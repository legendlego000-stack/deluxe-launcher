FAQ

Коротко о главном

Где взять рабочую ссылку на скачивание?

Создай GitHub Release в своём репозитории, приложи готовый установщик и замени переменную DOWNLOAD_URL внизу этого index.html на прямую ссылку на файл из Assets релиза.

Нужно ли вручную скачивать Java?

Нет, если оставлена автоматическая настройка и доступен интернет: лаунчер может скачать поддерживаемую версию Temurin JDK. Также можно указать путь к уже установленной Java в настройках.

Почему Windows может предупреждать о файле?

Новый или неподписанный установщик иногда вызывает предупреждение SmartScreen. Это не доказывает ни наличие, ни отсутствие вируса. Проверь источник, подпись, хэш и результаты независимой проверки до запуска.

Работает ли сайт без внешних библиотек?

Да. Страница использует встроенные HTML, CSS и JavaScript, локальные изображения в папке assets и не требует внешних CDN или веб-шрифтов.
